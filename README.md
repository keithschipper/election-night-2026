# Election Night Bellwether Model (2026)

A live page projecting the 2026 Michigan Senate, NV-03, Nevada governor, Michigan attorney general and Nevada attorney general races from 16 early-reporting bellwether counties, blended with each race's own count as it comes in.

- `index.html` — the page (served by GitHub Pages).
- `data/bellwethers.json`, `data/targets.json` — 2024 baselines and model weights.
- `data/live_results.json`, `data/race_results.json` — election-night results from Decision Desk HQ, updated hourly Nov 3–6, 2026 by a scheduled Claude task.
